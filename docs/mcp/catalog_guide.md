# `catalog_guide`

How to fill the catalog, step by step: the service's own instruction for an agent the user asked to map repositories into projects, services and domains. It covers the order of the work, the rules of path masks and of the project document, and how to read what put_project answers. Read it before put_project. Takes no arguments.

Token scope: `read`.

## Example

Send these parameters to `tools/call`.

```json
{
  "name": "catalog_guide",
  "arguments": {}
}
```
