# SYNTHETIC DATA

Everything in this directory is invented and written by hand for the install guide of Memini
(docs/install.md).

- `thread.json` is one batch for the push API: a chat thread between three fictional people about a
  fictional nightly export. Nothing is copied from or derived from a real conversation, project or
  company.
- Addresses and links use reserved names only (`example.test`, `chat.example.invalid`).
- No real person, company, message, credential, token or key.

Keep it that way: a change to this directory adds invented content only (CLAUDE.md, "Never commit").
