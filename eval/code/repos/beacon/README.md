# Beacon

Агент телеметрии для автоматических маяков: следит за вращением линзы, зарядом батарей и
туманным горном и отправляет показания на береговую станцию. Синтетический проект для оценки
поиска Memini; маяков с таким агентом не существует.

## Установка

Агент собирается командой `go build ./cmd/beacon`, и бинарный файл копируется на контроллер
маяка. Ему не нужны внешние библиотеки, только стандартная библиотека Go.

Веб-панель собирается отдельно: `npm run build` в каталоге `web`. Готовые файлы кладутся на
береговую станцию рядом с приёмником пакетов.

## Настройка датчиков

Файл `beacon.toml` задаёт адреса датчиков: датчика освещённости, датчика видимости и контроллера
батарей. Период опроса по умолчанию — тридцать секунд, его меняет флаг `-interval`.

Датчик, который не ответил три опроса подряд, считается отказавшим, и агент поднимает тревогу.
Показания такого датчика в пакет не попадают.

## Протокол сигналов

Агент отправляет пакет раз в минуту одной строкой JSON: время, заряд батареи, обороты линзы,
видимость и состояние горна. Адрес береговой станции задаёт флаг `-station`.

Если связи с берегом нет, пакеты копятся в очереди и уходят все сразу, по порядку, когда связь
вернётся. Очередь не теряется, пока агент работает.

## Журнал событий

Тревоги пишутся в журнал с уровнем важности: низкий заряд батареи, остановка линзы, отказ горна,
отказ датчика. Одинаковые тревоги одного маяка в течение пятнадцати минут не повторяются.

Журнал хранится тридцать дней, потом старые записи удаляются. Тревоги уровня «авария» уходят на
берег вне очереди.
