# Жернов

Жернов планирует работу небольшой пекарни: сколько закваски поставить с вечера, в какую печь и в
каком порядке ставить партии, сколько муки осталось на складе. Синтетический проект для оценки
поиска Memini; такой пекарни не существует.

## Установка

Нужен Python 3.12. Пакет ставится командой `pip install -e .` в отдельное виртуальное окружение;
внешних зависимостей у него нет.

Настройки лежат в файле `zhernov.toml` в рабочем каталоге. Команда `zhernov check` проверяет файл
и сообщает о каждой ошибке с номером строки.

## Конфигурация

В `zhernov.toml` перечислены печи (вместимость в противнях и предельная температура), склады и
рецептуры. Единицы измерения — килограммы и градусы Цельсия, время — в минутах.

Неизвестный ключ в файле считается ошибкой, чтобы опечатка не прошла незамеченной. Значения по
умолчанию есть у всего, кроме списка печей.

## Расчёт закваски

Закваску ставят с вечера. Её масса — доля от муки всех завтрашних замесов, и доля зависит от
температуры в цехе: чем холоднее, тем больше закваски. При восемнадцати градусах берут сорок
процентов от муки, при двадцати шести — двадцать.

Расчёт делает функция `starter_mass`; подкормку на утро считает функция `feeding`.

## Расписание печей

Партии ставятся в печи по убыванию температуры выпечки, чтобы печь между партиями только
остывала и не тратила время на разогрев. Партия не делится между печами.

Каждая партия идёт в наименее загруженную печь, которой хватает вместимости и предельной
температуры. Если такой печи нет, план не строится, и технолог видит, какая партия не поместилась.

## Отчёты

Ежедневный отчёт показывает выпуск по изделиям, процент брака и остаток муки на складе. Отчёт
уходит технологу в конце смены, а копия остаётся в журнале.

Сорта муки, которых осталось меньше минимального запаса, отмечаются в отчёте отдельно, чтобы их
успели заказать.
