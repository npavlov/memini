# Рецептуры

Рецептуры изделий пекарни: сырьё, брожение, режим выпечки и правила хранения.

## Ржаной хлеб на закваске

Мука ржаная обдирная, вода, соль и спелая закваска. Тесто бродит девяносто минут, расстойка
длится сорок минут во влажной камере.

Хлеб выпекают десять минут при двухстах тридцати градусах, затем ещё сорок минут при двухстах.
Готовый хлеб остывает на решётках не меньше часа, прежде чем его режут.

## Пшеничный батон

Мука пшеничная высшего сорта, молоко, дрожжи, сахар и сливочное масло. Тесто замешивают до
гладкости и дают ему подойти час при тёплой температуре.

Батон выпекают двадцать пять минут при двухстах десяти градусах, с паром в первые пять минут.
Надрезы делают перед самой посадкой в печь.

## Хранение муки

Мешки с мукой лежат на поддонах, не ближе полуметра от стены, при влажности воздуха не выше
семидесяти процентов. Новые поставки ставят позади старых.

Партию, которая пролежала больше полугода, отправляют на проверку в лабораторию. Мешок со
следами влаги списывают сразу.
